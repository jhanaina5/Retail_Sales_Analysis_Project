**Retail Sales Analysis| Excel, Power BI & SQL**


**Project Overview**


This project analyzes retail sales data to understand sales performance, profitability, product trends,
regional performance and, product returns. It demonstrates data preparation, exploratory analysis,
SQL querying, interactive dashboard development.


**Tools & Technologies**


**>Microsoft Excel**: Data cleaning,preparation and analysis.

**>Power BI:** Interactive dashboard,visualizations and business insights

**>SQL Server:** Data querying,aggregations,joins,subqueries and windows functions.


**Project Structure**
>01_Excel/- Source datasets and prepared Excel files
>02_PowerBI/- Power BI dashboard file
>03_SQL/-SQL setup,analysis and cleanup scripts


**Analysis Performed**


>Overall sales,profit and quantity analysis
>Regional and category-wise performance
>Monthly sales and profit trends
>Top-selling and loss-making products
>Discount-wise sales and profit analysis
>Order returns and regional manager lookups
>Profit classification using conditional logic
>Advanced analysis using subqueries and ranking functions


**Key Objectives**
>Identify sales and profitability trends
>Compare performance across regions and categories
>Highlight products generating losses
>Explore the relationship between discounts and profitability
>Present findings through an interactive Power BI dashboard


**How to explore This Project**
1.Review the datasets and prepared files in 01_Excel/.
2.Open the .pbix file in Power BI Desktop to explore the dashbaord
3.Open the SQL scripts in the SQL Server Management Studio(SSMS)to review the analysis queries


**Note:** The SQL scripts are intended for SQL Server.Review the database setup and cleanup scripts
before executing them.The People table cleanup script contains a DELETE statement and should only be run after verifying
the targeted records.
